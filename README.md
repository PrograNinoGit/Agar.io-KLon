# Agar.io Clone (Java Swing / AWT)

Ein in Java entwickeltes 2D-Game-Projekt nach dem Vorbild von **Agar.io**. Das Projekt demonstriert die praktische Anwendung von objektorientierter Programmierung (OOP) sowie die Umsetzung eigener Rendering- und Kollisionslogik mit Java Swing/AWT.

---

## 🛠 Features

- **Spieler-Steuerung:** Dynamische Bewegung der Spielfigur basierend auf der Mausposition.
- **Bot-Logik:** Automatische Bot-Gegner, die sich eigenständig über die Karte bewegen.
- **Game-Loop & Rendering:** Benutzerdefiniertes Rendering mit flüssigen Bildwiederholraten.
- **Kollisionserkennung:** Mechanismus zum Einsammeln von Ressourcen und Wachsen der Spielfigur.

---

## 💻 Technologien & Konzepte

- **Sprache:** Java
- **GUI & Rendering:** Java Swing / AWT
- **Architektur:** Objektorientierte Programmierung (OOP), Game Loop pattern, Event-Handling
